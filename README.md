# GEOGENEALOGIE

Démonstrateur d'arbre de filiation **ARTSGIS · geogenealogie**.

Cette page affiche un diagramme de filiation à cases, relié à une carte ArcGIS Online. **Les données restent privées sur AGOL** : ce dépôt ne contient que le code de la page, aucune donnée nominative.

- Page : [https://artsgis.github.io/GEOGENEALOGIE/](https://artsgis.github.io/GEOGENEALOGIE/)
- Mode démo (personnes fictives A à H, sans connexion) : [https://artsgis.github.io/GEOGENEALOGIE/?demo=1](https://artsgis.github.io/GEOGENEALOGIE/?demo=1)
- Pour les données réelles, une connexion au portail ArtsGIS est obligatoire. Un visiteur sans compte autorisé ne voit rien.
- Le coffre de travail reste le dépôt privé [ArtsGIS/GEOGENEALOGIE_p](https://github.com/ArtsGIS/GEOGENEALOGIE_p).

Règle : code public, données privées. Rien n'est partagé côté données sans l'accord du propriétaire.
